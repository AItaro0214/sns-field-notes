このページについて

個別の話題の細部ではなく、「物がどうハマっていくか（広がり方の型）」と「コミュニティがどう作られていくか」を、界隈カテゴリごとに追いかけます。日々の観測で目立った動きがあったカテゴリに、その日の記録と型の気づきを足していきます。本格的にリサーチしたい界隈が出てきたときに、ここからすぐ振り返れるようにするための台帳です。
